# Chroma-key test media

These files are development fixtures and are not copied into the release archive.

- `greenscreen-video.webm` — [EXPLOSION green screen](https://commons.wikimedia.org/wiki/File:EXPLOSION_green_screen_(no_copyright)_-_the_chosen_one_(720p,_h264).webm), by the chosen one, licensed under CC BY 3.0. Use a green key.
- `greenscreen-image.png` — PNG conversion of [John Chroma key 1.jpg](https://commons.wikimedia.org/wiki/File:John_Chroma_key_1.jpg), by John Coleman/KUSI-TV, released into the public domain. Pick the background shade from the image.
- `greenscreen-animation.gif` — [Animexample.gif](https://commons.wikimedia.org/wiki/File:Animexample.gif), by Branko, released into the public domain. Use `#FFFFFF` to test arbitrary-color keying.
