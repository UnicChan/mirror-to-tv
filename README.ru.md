# mirror-to-tv

Утилита для передачи изображений, анимированных GIF, видео поверх других приложений и аудио с компьютера Windows на телевизор по локальной сети. Исходный код полностью открыт; облачные сервисы не используются.

## Совместимость

### Проверенная конфигурация

| Компонент | Характеристика |
| --- | --- |
| Платформа телевизора | Xiaomi `MiTV-MOSR1` / `hermano_eu`, используется в 32-дюймовых моделях Xiaomi TV A2 и P1E |
| Операционная система | Android TV 11 (API 30) |
| Архитектура | ARMv7 |
| Память | 1,5 ГБ оперативной, 8 ГБ встроенной |
| Аппаратная конфигурация Xiaomi TV A2 32 | 1366 × 768 при 60 Гц, четырёхъядерный Cortex-A55, Mali-G31 MP2, двухдиапазонный Wi-Fi ([официальные характеристики](https://www.mi.com/global/product/xiaomi-tv-a2-32/specs/)) |

### Поддержка платформ

| Платформа | Статус | Требования и примечания |
| --- | --- | --- |
| Android TV / Google TV | Ожидается совместимость | Android 6.0 (API 23) или новее; поддержка ADB по локальной сети и разрешения `Показывать поверх других приложений` в прошивке. Другие модели не проверялись. |
| Amazon Fire TV | Ожидается совместимость, не проверено | Fire OS 6 или новее; эти версии основаны на Android API 25 или новее и поддерживают сетевое подключение ADB ([документация Amazon](https://developer.amazon.com/docs/fire-tv/fire-os-overview.html)). |
| Samsung Tizen, LG webOS, Roku, Apple TV | Не поддерживается | Для приёмника требуются Android API. |
| Компьютер Windows | Поддерживаемая платформа контроллера | Windows 10 или Windows 11. |

## Установка

Телевизор и компьютер должны быть подключены к одной домашней сети.

### Что потребуется после скачивания релиза

Дополнительно устанавливать программы на компьютер не нужно: APK, ADB и FFmpeg уже входят в `mirror-to-tv-1.0.zip`. Нужно только включить ADB-отладку на Android TV, узнать IP-адрес телевизора и полностью распаковать архив на компьютере с Windows 10 или 11.

### 1. Подготовка телевизора

1. Откройте **Настройки → Об устройстве → Модель продукта** и семь раз нажмите кнопку OK. Xiaomi указывает этот способ для открытия доступа разработчика на Mi TV и Mi Box ([инструкция Xiaomi](https://www.mi.com/uk/support/article/KA-06513/)). В некоторых прошивках Android TV и Google TV этот пункт называется **Сборка**.
2. Вернитесь в **Настройки → Аккаунт и безопасность**, откройте **Отладка ADB** и выберите **Разрешить**.
3. Откройте **Настройки → Сеть и Интернет → подключённая сеть Wi-Fi или Ethernet**. Запишите показанный там **IP-адрес**, например `192.168.1.50`.

### 2. Установка и запуск

1. Скачайте `mirror-to-tv-1.0.zip` со страницы Releases репозитория и полностью распакуйте архив. Не запускайте файлы непосредственно из ZIP.
2. Запустите `Install-Mirror-To-TV.cmd`, чтобы установить или обновить APK. Введите IP-адрес телевизора и оставьте стандартный ADB-порт `5555`, если телевизор не показывает другой порт.
3. Если на телевизоре появится запрос авторизации, выберите **Всегда разрешать с этого компьютера**, затем нажмите **Разрешить**.

Установщик подключится к телевизору, установит APK, выдаст разрешение на показ поверх других приложений, закроет открытый системный экран разрешения, запустит и проверит приёмник, сохранит адрес телевизора и откроет desktop-панель. Телевизор при этом не перезагружается. Для обновления APK снова запустите `Install-Mirror-To-TV.cmd` — сохранённый адрес подставится автоматически. Если подпись APK отличается, установщик предложит полную переустановку; без подтверждения установленное приложение не удаляется. Для обычного запуска используйте `Start-Mirror-To-TV.cmd`.

ADB уже включён в релизный архив, поэтому Android Studio не требуется. Уведомления Apache 2.0 для ADB находятся в `tools/NOTICE.txt`. Если подключение не устанавливается, убедитесь, что компьютер и телевизор находятся в одной негостевой сети, а в роутере не включена изоляция Wi-Fi-клиентов.

## Прозрачность chroma key

1. Добавьте изображение, анимированный GIF или видео и выберите его слой в области предпросмотра.
2. Откройте **CHROMA KEY** и включите удаление однотонного фона. Стандартный цвет — `#00FF00`.
3. Для другого оттенка нажмите **PICK FROM SCREEN**, затем укажите нужный цвет в любой точке рабочего стола Windows. Допуск и мягкость края меняйте только при необходимости.
4. Включите трансляцию. Первая отправка может занять больше времени, пока компьютер готовит прозрачность; результат кэшируется до изменения исходного файла или настроек chroma key.

Изображения и GIF преобразуются в прозрачные медиафайлы на ПК. Видео на ПК преобразуется в H.264-поток с готовым цветным кадром и альфа-маской. Телевизор использует аппаратное декодирование видео и небольшой GPU-шейдер только для применения уже рассчитанной маски. FFmpeg входит в релизный архив, не устанавливается на телевизор, а его лицензия находится в `tools/FFMPEG-LICENSE.txt`.

## Сборка из исходников

Для обычного использования этот раздел не нужен. Для сборки релиза установите или распакуйте:

1. [JDK 17](https://learn.microsoft.com/en-us/java/openjdk/download) в `C:\Tools\jdk-17`.
2. [Android Studio](https://developer.android.com/studio/install) со стандартными Android SDK, Build-Tools и Platform-Tools. Стандартный путь SDK определяется автоматически.
3. [FFmpeg для Windows](https://ffmpeg.org/download.html) в `C:\Tools\ffmpeg`, чтобы исполняемый файл находился по пути `C:\Tools\ffmpeg\bin\ffmpeg.exe`.

Затем запустите `Build-And-Install-Mirror-To-TV.cmd` из корня проекта. Он соберёт релиз и установит или обновит APK на телевизоре. При первом запуске потребуется IP-адрес телевизора; следующие обновления используют сохранённый адрес. Готовый архив появится в `dist`.
